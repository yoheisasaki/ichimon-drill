# 風助のRPGをスマホとiPadで共有する設定

## 現状
- 学習履歴 API (`?api=ichimon_history`) は稼働済み。
- RPG の共有 API (`?api=ichimon_game`) は 2026-11-23 に学習ボードへ組み込み・再デプロイ済み（@71、URL は従来どおり）。共有鍵は父が管理（GitHub には置かない）。保存ファイルは Google ドライブ 02_記録 の `ichimon-rpg-cloud-save.json`。下の「学習ボード Apps Script」の手順は完了済み。
- アプリ側のUI・クラウド同期クライアントは実装済み。API 未設定時はゲームを端末内に保存し続けます。学習・装備・建築は消しません。

## 学習ボード Apps Script（オーナーによる作業）

1. 学習ボードの Apps Script を開き、先に **現行 Code.gs とスプレッドシートのバックアップ**を作る。
2. このリポジトリの `docs/RPGクラウド同期_GAS.gs` を Code.gs に追記（コード末尾にそのまま貼る）。
3. **既存の doGet(e) に** 次の分岐を追加（既存の `ichimon_history` や `ichimon_conf` の分岐は残す）。

```javascript
if (e.parameter && e.parameter.api === 'ichimon_game') {
  return json_(ichimonGameGet_(e.parameter.key));
}
```

4. **既存の doPost(e) の冒頭付近**で、受信 JSON をパースした後、通常の一問一答の記録処理へ入る前に次を追加。パース済み変数があれば再利用すること。二重パースや同名変数宣言を避ける。

```javascript
const incomingGame = JSON.parse(e.postData && e.postData.contents || '{}');
if (incomingGame.api === 'ichimon_game') {
  return json_(ichimonGamePost_(incomingGame));
}
```

5. Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に `ICHIMON_GAME_KEY` を登録する。値は **推測されにくい20文字以上の共有鍵**。GitHub やHTMLに書かず、保護者が管理する。
6. ウェブアプリとして**新バージョンをデプロイ**。既存 `SEND_URL` と同じ公開 URL で動くよう、既存デプロイを更新する（新デプロイでURLが変わった場合は `common.js` の `SEND_URL` を更新する必要あり）。DriveApp/PropertiesService の追加権限が求められたら内容を確認して承認する。
7. **API確認**：`?api=ichimon_game&key=<共有鍵>` のGETで `{"ok":true,"version":0,"save":null}` が返るか確認（まだ保存前の場合）。鍵を含むURLをSNSなどに共有しない。

## アプリでの初期設定（必ずこの順序）

1. **もっとも進行している風助の端末**で、学習履歴やゲームデータのバックアップを書き出しておく。
2. その端末でアプリを更新→「自分」→「設定」→「スマホ・iPadのRPG共有」へ。共有鍵を入力し「クラウドを確認」。空であることを確認してから **「この端末を初回保存」** を押す。
3. もう一方の端末も更新し、同じ共有鍵で「クラウドを確認」→ **「クラウドから読み込む」**。現端末のデータは読み込み前にローカルバックアップされる。
4. 以後は、正常な接続中ならRPGセーブの変更が自動アップロードされ、画面が再びアクティブになったときに最新が取り込まれる。
5. **二台で同時に遊ばない**。同時変更が起きたときは自動上書きを止める（競合メッセージが表示される）。どちらを残すか確認してから手動で解決する。
6. 通信エラーのときは端末データを保護。別の端末に移る前に接続できているか確認する。

## なぜこの方式か
- ゲームの保存を端末からいきなりクラウドで置き換えることはせず、保護者が **最初の正本** を指定する。
- 競合を防ぐためクラウドの `version` を毎回照合し、古いバージョンで上書きできないようにする。
- 共有鍵がない端末ではアクセス不可。ママ用の学習記録と混ぜない。
- 学習履歴の共有APIはそのまま、RPGの装備・職業・宝箱・ペット・建築をまとめて1つの保存データにする。

## 留意点
APIの組み込み・再デプロイは、このリポジトリのコミットだけでは完了しません。アプリの設定画面を押しても、APIがまだ公開されていなければ接続できません。**接続できない状態で既存の端末データを消さないこと。**
