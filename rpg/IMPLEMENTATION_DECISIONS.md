# 仕様補完・判断の記録（DECISIONS）

設計書の「補完」と、設計書に書かれていなかった点の実装判断。根拠の数値は `TEST_REPORT.md` と `rpg/tools/*.js`。

- D-01 作業場所：git worktree `.worktrees/rpg`（ブランチ rpg）。master の毎時問題追加と競合しない。push・公開なし。
- D-02 構成：ビルド無しのまま、DOM非依存の純粋関数モジュール（UMD、node とブラウザの両方で読める）。`rpg-data`（職・技・敵・装備）／`rpg-core`（成長・日次・抽選・保存）／`rpg-battle`（戦闘・乱数なし）／`rpg-adventure`（冒険進行）／`rpg-ui`（画面）。問題データ（data/）には一切触れない。
- D-03 保存：`ichimon.rpg.v1`（学習キーと別）。保存のたびに revision を比べ、別タブが先に進んでいたら上書きせず「よみこみなおして」を出す（stale）。setItem が失敗・読み戻しが違う場合は成功扱いにせず、ゲームだけ止めて案内（学習は続く）。壊れたセーブは新規に置き換えず（上書きで失う恐れ）RPGを止めて案内。
- D-04 回答イベントの台帳：学習記録の `rid` をそのままイベントIDに使い、`active.events` で重複を弾く（同一ridは無視）。冒険IDは `adv<連番>-<時刻>`、基本回答の起点IDは `<冒険ID>:b<n>`。結果の再表示は `lastResult` を読むだけで副作用なし。
- D-05 冒険と学習セッション：1冒険＝基本10＋復習（最大5/冒険）。セッションはアプリの「回」。開始時に残り基本回答数（10−済）で出題数を切り詰め、未完了の復習を先頭に出す。10問未満しかない範囲は累積。手動の「まちがえたのだけ もう1回」は `manual` 扱いで冒険に一切影響しない（報酬・戦闘とも）。次の通常スタート／つぎの10もん／にがては新しい基本回答。
- D-06 再出題の位置：現行は `idx+3` に挿入＝間に2問はさむ。実測（regress.py）で確認し、変更しない。復習で再度誤答すると、上限（5/冒険）まで再度予約する（現行の挙動を維持）。
- D-07 敵の能力値：道のり番号 g（0..71）の曲線 `CURVE`（rpg-data.js）×敵ごとの係数。主人公の育ち方（`sim.js --steps`、戦士→魔法使い→魔法戦士、毎日2回）から、道中は「正解6〜7件＋技で1冒険」、ボスは約3冒険になるよう設定。最初のスライムは初期装備で正解5件前後（テストで固定）。プレイ中の正答率で隠れて増減しない。敵の攻撃力は計算値の1.3倍（30%で撤退が時々起き、60〜80%ではまず撤退しない強さ）。
- D-08 装備：ランクI〜VIの通常60種は設計書の価格・性能。ランクI以外の名前、全レアの名前・効果（ランクI の4種＋朝露のローブ以外）は仮名・仮効果（`provisional:true`）。レアは分類（剣/杖/短剣/弓/防具/アクセ）×ランクで全て存在し、宝箱の候補が空にならない（テスト）。防具3種・アクセ3種の通常効果は設計書I表のとおり、II以降は同じ効果を上限内で増加。
- D-09 弱点：敵の弱点は最初から表示される前提（「発見済み」＝常に発見済み）。全職共通。魔法戦士の虹の一閃・賢者の三元素の術はこの値を参照する。
- D-10 技AI：①倒し切れる最小消費 → ②予告された大技が致死／最大HPの40%以上（守る25%、攻める＝致死のみ）なら防御技（軽減が上がるもの）→ ③HPが閾値（おまかせ40%・攻める25%・守る65%）以下なら回復 → ④ゲージ1あたりの上乗せが近い技を「この戦闘で使った回数が少ない順」に回す。大技のためゲージが4足りない範囲までは通常攻撃でためる。ゲージ満タンは上乗せ最大の技を使う。行動の評価は状態を複製して実際に計算（先読みはしない・未知の情報は使わない）。通常攻撃は常に候補。
- D-11 継承技：元職の固有能力（印・影・守護・調和・照準・星・属性まとい・飛翔）は発動しない。職業Lv15/25の技強化は、その職自身の技にだけ掛ける（継承時は基本値）。継承枠は基本職のどれかがLv5以上で開き、継承は1枠まで（設計書01の「1枠に他職の継承可能技」）。
- D-12 日次枠：JST午前4時切替。最初の基本回答時に予約し冒険に固定。端末時計が巻き戻ってもこれまでに見た最新の日より前にならない（`daily.maxKey`）。時計を進める操作は防げない（設計書どおり技術上の限界。オンライン必須にはしない）。
- D-13 宝箱：日次1・2枠の冒険を清算すると1個。結果（種類・装備）は清算時に確定してセーブに入れ、同時に反映する（開封の別操作は第2段）。抽選はシード（冒険ID）で再現でき、再読込で変わらない。レアが4回出なければ5個目確定。レア重複は同ランク素材3個（ランク素材は共通ID `ore_<ランク>`、名前「ランクIのこうせき」は仮）。
- D-14 清算：XP・コインは回答ごとに「獲得予定」（回答数と正解数）を保存し、清算時に1回だけ残高へ。冒険者XPと冒険開始時の職業XPに全量。上限到達後はその系統のXP増加だけ停止。討伐コイン 通常15、ボス初回は地域表、ボス再戦30（未使用）。登録祝い160は最初の清算で1回。
